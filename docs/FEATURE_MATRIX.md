# Đối chiếu chức năng GPMLoginGlobal và bản thay thế

Phạm vi người dùng yêu cầu: Windows x64 và macOS Intel (x64), toàn bộ chức năng của bộ cài đã gửi. Tài liệu này là danh mục điều tra và tiêu chí nghiệm thu; **không xác nhận bản thay thế đã triển khai hoặc tương đương toàn bộ sản phẩm**.

## Điều kiện tương đương trên Windows và macOS Intel

1. Có bản build x64 riêng cho mỗi OS; việc tạo archive không thay cho khởi chạy kiểm thử. macOS cần ký/notarize nếu muốn phân phối không gặp Gatekeeper; chứng chỉ thuộc chủ phát hành. Windows cũng cần kiểm thử cài đặt, uninstall, quyền filesystem và executable.
2. Bộ cài được kiểm tra là Windows. Các đường dẫn và plugin `.exe` trong gói không chứng minh hành vi của bản macOS gốc. Chưa có mẫu macOS để đối chiếu.
3. Phải lập test theo từng ID phía trên trên máy Windows và Intel Mac, dùng profile tạm, dữ liệu mẫu và tài khoản thử. Các test Linux hoặc mock không xác minh hành vi desktop của hai OS đích.
4. Browser engine tiêu chuẩn có thể thực hiện profile isolation, proxy, cookies và CDP. Cơ chế fingerprint, patch engine, UDP/route proxy và compatibility extension cần kiểm thử riêng. Không ghi “anti-detect tương đương”, “ẩn fingerprint hoàn toàn” hoặc “tất cả extension” khi chưa đo.
5. Cloud, tài khoản, chia sẻ, license, updater, cửa hàng và automation bên ngoài cần hợp đồng dịch vụ/định dạng thực hoặc triển khai độc lập rõ tên. UI placeholder, dữ liệu giả, nút không hoạt động hoặc trang “coming soon” không được tính là hoàn thành.
6. Bản thay thế độc lập không tự động đọc được profile/database/export/project/plugin GPM. Mọi chuyển đổi dữ liệu phải có fixture gốc đã thử và báo rõ mất mát trường.

## Ưu tiên điều tra tiếp theo

- Gắn mỗi chức năng triển khai với ID F01–F29 và test cụ thể; duy trì trạng thái “đã triển khai”, “đã kiểm thử Linux”, “đã kiểm thử Windows”, “đã kiểm thử macOS Intel”, “chưa hỗ trợ” riêng biệt.
- Đọc `sample_excel_import.xlsx`, schema cấu hình cache/font và tool helper để xây fixture nhập/xuất. Không suy ra schema chỉ từ nhãn UI.
- Cần các profile/export/project mẫu do người dùng chủ động cung cấp, đã loại dữ liệu riêng tư, để kiểm thử compatibility GPM.
- Phân tích native theo câu hỏi có mục tiêu: entry point launch browser, đọc/ghi database, định dạng export, giao thức local API, quy trình extension. Không mở rộng sang gọi API máy chủ thật hoặc dùng credential tìm được trong mẫu.
- Giữ thông tin proxy, cookie, token và dữ liệu hồ sơ ngoài log/report. Không truy cập URL backend từ chuỗi nhị phân chỉ vì thấy trong mẫu.
